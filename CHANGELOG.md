## [0.1.0] — 2026-11-19

Первая версия.

### Добавлено
- Каталог: музыканты, ансамбли и их состав, диски, история цен, остатки (#1).
- Продажи с контролем остатка и фиксацией цены на дату продажи (#1).
- Авторизация, роли `admin` и `seller` (#1).
- JSON API с единым форматом ошибок, `/health`, журнал с `X-Request-ID` (#1).
- Веб-интерфейс: каталог, карточка диска, продажи, отчёты, управление (#1).
- Отчёт «лидеры продаж» (#1) и «заканчиваются на складе» (#3).
- Версия приложения и ссылка на репозиторий в подвале страницы (#5, #6).
- Миграции Alembic, `make verify`, CI на GitHub Actions, правила внесения изменений.
